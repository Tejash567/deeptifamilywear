# Deepti Family Wears Showroom

Build a premium, modern, responsive website for a local clothing store called "Deepti Family Wears".

This is NOT an ecommerce website. It is a premium digital showroom designed to build trust, showcase products, increase store visits, and encourage customers to contact the shop through WhatsApp or phone.

The business is located in Main Market, Jhabrera, Uttarakhand and serves customers from Jhabrera, Roorkee, Bhagwanpur, Manglore, Puhana, nearby villages and surrounding areas.

The store specializes in:

• Men's Wear

• Women's Wear

• Kids' Wear

• School Uniforms

Do NOT mention any clothing brands.

Instead, emphasize:

• Premium Quality

• Fixed Price Shop

• Honest Pricing

• Reasonable Prices

• Latest Designs

• Large Variety

• Trusted Local Store

• Excellent Customer Service

The overall design should feel similar to premium fashion brands while remaining warm, trustworthy and welcoming for families.

The website should use a clean luxury aesthetic with:

Background:

White

Primary Color:

#0F172A (Deep Navy)

Accent:

#C8A74E (Elegant Gold)

Secondary:

Light Grey (#F8F9FA)

Typography:

Modern, elegant sans-serif.

Lots of whitespace.

Rounded corners.

Soft shadows.

Glassmorphism only where appropriate.

Animations should be subtle and smooth.

Use Framer Motion for animations.

Everything should be fully responsive for desktop, tablet and mobile.
